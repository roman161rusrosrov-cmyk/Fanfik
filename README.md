# Семь минут

Атмосферный сайт-читалка для фанфика об Амире и Роме: 60 расширенных глав, 71 295 слов, 120 фотосцен без лиц и завершённая первая часть с открытым продолжением.

## Что есть на сайте

- полный текст всех 60 глав;
- адаптивный дизайн для компьютера и телефона;
- быстрый поиск по всему фанфику;
- сохранение последней главы и позиции чтения;
- закладки;
- тёмная и светлая темы;
- изменение размера текста;
- режим без отвлечений;
- офлайн-доступ после первого открытия;
- по две фотосцены в каждой главе — 120 изображений;
- полноэкранный просмотр кадров;
- отдельный раздел двух семей: Арчи, Арсен, родители, тётя из Бердянска, дядя, тётя и Тимур;
- сюжетная арка падения отца Ромы с УАЗа и восстановления.

## Сайт

После включения GitHub Pages он будет доступен по адресу:

**https://roman161rusrosrov-cmyk.github.io/Fanfik/**

Публикация выполняется автоматически через workflow `.github/workflows/pages.yml` после каждого изменения ветки `main`.

## Локальный запуск

Из корня репозитория:

```bash
python -m http.server 8080
```

Затем открыть `http://localhost:8080`.

Обычное открытие `index.html` двойным кликом не подойдёт: браузеру нужен локальный сервер, чтобы загрузить `story.html`.

## Структура

```text
assets/                  обложки и 120 фотосцен глав
.github/workflows/       публикация GitHub Pages
index.html               главная страница и читалка
styles.css               дизайн и адаптивность
app.js                   логика чтения, поиска и сохранений
story.html               полный текст фанфика
manifest.webmanifest     установка сайта как приложения
sw.js                    офлайн-кэш
```

Все изображения созданы специально для этой истории и не изображают реальных людей.
